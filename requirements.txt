# bundles ~1.5-2GB of unused CUDA/GPU libraries -- Render's free tier has no GPU, so that
# bloat does nothing but eat RAM and disk and slow the build down. This line points pip at
# PyTorch's own CPU-only wheels instead, which are a fraction of the size.
