Under the hood

How it works

Style transfer happens in a single forward pass, using Adaptive Instance Normalization (AdaIN).

01

Encode

A fixed, pre-trained VGG-19 network turns both images into feature maps describing content and style.

02

Match statistics

AdaIN rescales the photo's features so their mean and variance match the painting's — this is where the look transfers.

03

Blend

The style strength slider mixes the matched features with the original ones, from the original photo to the full style.

04

Decode

A decoder network, trained from scratch by us, turns the blended features back into a final image.

AdaIN(x, y) = σ(y) · (x − μ(x)) / σ(x) + μ(y)

Based on Huang & Belongie, Arbitrary Style Transfer in Real-Time with Adaptive Instance Normalization (ICCV 2017).

Questions

FAQ

Is the whole model pre-trained?
Partly. The encoder is a pre-trained VGG-19 network, used as a fixed feature extractor and never updated. The decoder, which turns stylized features back into an image, was trained from scratch for this project.
Which styles of painting can I use?
Almost any image — impressionist, cubist, abstract, a sketch, a texture, even a photo. AdaIN works on the feature statistics of whatever style image you give it, it isn't limited to a fixed list.
What's the tech stack?
Python, PyTorch for the model, Flask for the backend, and plain HTML/CSS/JS for this interface.
What was the decoder trained on?
Photographs for content and a collection of artworks for style, following the original AdaIN paper's recipe.
Does output quality actually change anything?
Yes. Both the encoder and decoder are fully convolutional, so resizing the input before inference really changes the processing size and the output size — it isn't a cosmetic setting.
